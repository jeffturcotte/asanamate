# Deprecated features

Deprecated features remain supported for compatibility. Use the replacement
in new commands and scripts. Removal requires a future breaking release;
no removal version is scheduled yet.

| Deprecated | Replacement | Behavior |
| --- | --- | --- |
| `--no-preview` | `--hide-preview` | Starts the TUI with the preview hidden. `z` can still show or hide it; the sidebar remains independent. Both flags set the same option. |
